# AGENTS.md — контракт репозитория-харнесса

Это база агентной разработки на Rust: универсальный скилл + шаблон сервиса.
Сам репо — НЕ проект: здесь ничего не собирается и не деплоится.

## Карта

| Путь | Что это | Для кого |
|---|---|---|
| `skills/rust-development/` | Универсальный скилл Rust-разработки (SKILL.md + reference.md). Ставится symlink'ом в `~/.zcode/skills/rust-development` | Агент на любой Rust-задаче |
| `templates/rust-service/` | Рабочий шаблон сервиса (axum + PostgreSQL + Redis + RabbitMQ). Копируется целиком под новый проект | Старт сервисного проекта |
| `.github/workflows/ci.yml` | CI шаблона (working-directory `templates/rust-service`) | Проверка шаблона в этом репо |

## Правила работы с этим репо

- Правки скилла делаешь здесь и коммитишь; `~/.zcode/skills/rust-development` — symlink, отдельной копии не существует.
- Правки шаблона — внутри `templates/rust-service/`; после правок гоняй его гейт (`cd templates/rust-service && just check && just test-int`) — шаблон обязан быть всегда зелёным, это его главный инвариант.
- Не смешивай зоны: универсальные правила — в скилле; правила конкретного сервисного проекта — в `templates/rust-service/AGENTS.md` (действует только внутри проектов, созданных из шаблона); одна строка-указатель на скилл — в глобальном `~/.zcode/AGENTS.md`.
- Язык: скилл — английский (конвенция скиллов), шаблонные контракты — русский/английский как сложилось в шаблоне.

## Как начать проект из шаблона

`cp -r templates/rust-service <новый репо>` → далее по README шаблона (`just setup`). Внутри нового проекта действует его собственный AGENTS.md (переименовывать крейты и править под проект — норма).
